# Settings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add persistent application settings for language, font size, theme, and safe local credential master-password changes.

**Architecture:** Store validated, export-excluded preferences in the existing SQLite database. Keep translation and document-preference application in focused frontend modules; the settings dialog submits narrow Tauri commands, while `SecretStore` atomically rewraps its existing data key for a master-password change.

**Tech Stack:** Vue 3, TypeScript, Vitest, Tauri 2, Rust, rusqlite, Argon2, XChaCha20-Poly1305.

## Global Constraints

- Preferences are exactly `language: system | zh-CN | en`, `fontSize: small | medium | large`, and `theme: system | light | dark`; defaults are `system`, `medium`, `system`.
- Preferences are device-local and never included in configuration JSON import/export.
- Explicit language selection translates every user-visible application string to Simplified Chinese or English; SSH values and JSON keys remain unchanged.
- Theme, font size, and language apply immediately after a successful save; `system` theme follows live OS media-query changes.
- Master-password change requires current password, new password, and confirmation; it preserves SSH secrets and all existing recovery codes.
- No master password, SSH credential, recovery code, encrypted payload, key, or preference error-sensitive input is exported, logged, stored in global frontend state, or returned in errors.
- Validate malformed backend payloads and stored preferences fail closed to defaults; never apply an unknown preference.
- Use TDD: run focused RED test first, then minimal implementation and GREEN test per behavior.

    let store = initialized_store();
    let code = store.recovery_code();
    let secret = store.put("ssh-password").unwrap();
    store.change_master_password("old password", "new password").unwrap();
    store.lock();
    assert!(store.unlock("old password").is_err());
    store.unlock("new password").unwrap();
    assert_eq!(store.get(secret).unwrap(), "ssh-password");
    assert!(store.recover(&code, "recovered password").is_ok());
}
